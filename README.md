# AssetShield Launcher

Быстрый запуск любых Roblox плейсов с оптимизацией загрузки ассетов.

## ⚡ Быстрый старт

### Windows (самый простой способ)
Просто запустите файл **`start.bat`** - всё установится и запустится автоматически!

### Другие системы
```bash
npm install
npm run dev
```

Затем откройте http://localhost:5173 в браузере.

## 📖 Подробная инструкция

Если возникли проблемы, смотрите [INSTALL.md](INSTALL.md)

## 🚀 Что это?

AssetShield Launcher — это программа, которая позволяет запускать любые игры Roblox от разных разработчиков с быстрой и стабильной загрузкой ресурсов.

### Для игроков:
- ✅ Не нужно ничего устанавливать в Roblox Studio
- ✅ Просто выберите игру или введите ID плейса
- ✅ Быстрая загрузка без багов и "невидимых" стен
- ✅ Работает с любыми плейсами от любых разработчиков

### Для разработчиков:
- ✅ Скачайте .bat файл лаунчера
- ✅ Запустите его и введите ID любого плейса
- ✅ Играйте с оптимизированной загрузкой

## 📥 Как использовать

### Веб-версия:
1. Откройте веб-приложение
2. Выберите игру из списка популярных плейсов или введите ID плейса
3. Нажмите "Запустить"
4. AssetShield автоматически оптимизирует загрузку

### Десктопный лаунчер (.bat файл):
1. Нажмите кнопку "Скачать лаунчер" на сайте
2. Запустите скачанный файл `AssetShield_Launcher.bat`
3. Введите ID плейса когда программа попросит
4. Игра запустится с оптимизацией

## 🎮 Как найти ID плейса?

ID плейса — это число в URL игры на Roblox:

```
https://www.roblox.com/games/2753915549/Blox-Fruits
                                    ^^^^^^^^^^
                                    Это ID плейса
```

## 🔧 Как это работает?

AssetShield Launcher:
1. Находит Roblox Player на вашем компьютере
2. Очищает старый кэш для быстрой загрузки
3. Запускает игру с оптимизированными настройками
4. Предзагружает критические ассеты перед стартом
