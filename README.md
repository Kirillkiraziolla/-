# 🚀 AssetShield Launcher

**Быстрый запуск любых Roblox плейсов с оптимизированной загрузкой**

---

## 📖 Что это?

AssetShield Launcher — это веб-приложение, которое позволяет запускать любые игры Roblox от разных разработчиков с быстрой и стабильной загрузкой ресурсов.

### ✨ Возможности:
- 🎮 Запуск любого плейса по ID
- 📋 Список популярных игр (Blox Fruits, Adopt Me!, Brookhaven и др.)
- 🔍 Поиск игр по названию, создателю или тегам
- ⚡ Оптимизированная загрузка ассетов
- 💾 Скачиваемый .bat файл для запуска без браузера

---

## 🚀 Как запустить локально

### Требования:
- Node.js 18+ ([скачать](https://nodejs.org/))
- npm (устанавливается вместе с Node.js)

### Установка:

```bash
# 1. Установить зависимости
npm install

# 2. Запустить проект
npm run dev
```

Откройте http://localhost:5173 в браузере

## 🌐 Как выложить в интернет (бесплатно)

### Способ 1: Netlify Drop (самый простой)

1. Соберите проект:
   ```bash
   npm run build
   ```

2. Откройте [netlify.com/drop](https://app.netlify.com/drop)

3. Перетащите папку `dist` на страницу

4. Готово! Получите ссылку вида `https://your-site.netlify.app`

### Способ 2: Vercel

1. Зарегистрируйтесь на [vercel.com](https://vercel.com)

2. Импортируйте проект из GitHub

3. Vercel автоматически соберёт и опубликует сайт

## 🎮 Как использовать

### Веб-версия:
1. Откройте сайт
2. Выберите игру из списка или введите ID плейса
3. Нажмите "Запустить"
4. Игра откроется в Roblox

### Десктопный лаунчер (.bat файл):
1. Нажмите "Скачать лаунчер" на сайте
2. Запустите скачанный файл
3. Введите ID плейса
4. Игра запустится с оптимизацией

