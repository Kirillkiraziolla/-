# 🚀 Инструкция по запуску AssetShield Launcher

## ⚠️ Ошибка "vite не является внутренней или внешней командой"

Эта ошибка означает, что зависимости проекта не установлены. Следуйте инструкции ниже.

---

## 📋 Пошаговая инструкция

### Шаг 1: Установите Node.js

Если у вас ещё не установлен Node.js:

1. Перейдите на сайт: https://nodejs.org/
2. Скачайте **LTS версию** (рекомендуется)
3. Установите, следуя инструкциям установщика
4. Проверьте установку:
   ```bash
   node --version
   npm --version
   ```

### Шаг 2: Откройте терминал в папке проекта

**Windows:**
- Откройте папку проекта в Проводнике
- В адресной строке введите `cmd` и нажмите Enter
- ИЛИ: Shift + правая кнопка мыши → "Открыть окно PowerShell здесь"

**Mac/Linux:**
- Откройте терминал
- Перейдите в папку проекта: `cd /путь/к/проекту`

### Шаг 3: Установите зависимости

В терминале выполните:

```bash
npm install
```

⏳ Это займёт 1-3 минуты. Будут установлены все необходимые пакеты.

### Шаг 4: Запустите проект

После установки зависимостей выполните:

```bash
npm run dev
```

✅ Вы увидите сообщение:
```
  VITE v6.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

### Шаг 5: Откройте в браузере

Откройте браузер и перейдите по адресу:
```
http://localhost:5173
```

🎉 Готово! AssetShield Launcher запущен!

## 🔧 Альтернативные способы запуска

### Способ 1: Через npm scripts

```bash
npm run dev
```

### Способ 2: Через npx (если vite не в PATH)

```bash
npx vite
```

### Способ 3: Прямой вызов из node_modules

**Windows:**
```bash
node_modules\.bin\vite
```

**Mac/Linux:**
```bash
./node_modules/.bin/vite
```

## 🛠️ Решение проблем

### Проблема: "npm не является командой"

**Решение:** Node.js не установлен или не добавлен в PATH.
- Переустановите Node.js с https://nodejs.org/
- Перезапустите терминал после установки

### Проблема: "Cannot find module 'vite'"

**Решение:** Зависимости не установлены.
```bash
npm install
```

### Проблема: Порт 5173 занят

**Решение:** Используйте другой порт:
```bash
npm run dev -- --port 3000
```

### Проблема: Белый экран в браузере

**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте ошибки
3. Попробуйте очистить кэш (Ctrl + Shift + Delete)

### Проблема: Ошибки TypeScript

**Решение:**
```bash
npm run typecheck
```

## 📞 Нужна помощь?

Если возникли проблемы:

1. Проверьте версию Node.js: `node --version` (должна быть 18+)

3. Выполните `npm install` заново
4. Перезапустите терминал
